# Antrian

Ini adalah website antrian sederhana

## Requirements
- Go >= 1.26

## Cara Menjalankan

```bash
git clone https://github.com/maroisa/antrian.git && cd antrian
go mod download
go build -o antrian .
./antrian
```

## Cara Development

```bash
go mod download
cd web

pnpm install
pnpm dev

cd ..

go run .
```
